# AKeyboard v0.5.1 (versionCode 5)

Google Play Internal Testing build `v0.5.1 (5)`.

## What's new

- **IME Edge-to-Edge & Adaptive Navigation Bar**: transparent IME navigation bar with dynamic light/dark icon contrast matching system theme, plus unified `navigationBars`, `mandatorySystemGestures`, and `displayCutout` safe insets.
- **Regional Availability Guard**: clearer error messages and setup notice when Google AI Studio API is unavailable in unsupported regions.
- **Live Client Reliability**: improved audio stream timing and explicit null handling in `GeminiLiveClient`.

## 更新內容（繁體中文）

- **鍵盤沉浸式 Edge-to-Edge 與自適應導覽列**：支援透明導覽列背景與依系統深淺色主題自動切換導覽列圖示反色，並整合 `navigationBars`、`mandatorySystemGestures` 與 `displayCutout` 安全邊距。
- **區域可用性提示**：針對不支援 Google AI Studio API 的地區新增明確的錯誤提示與設定說明。
- **語音連線穩定性優化**：修正 `GeminiLiveClient` 音訊串流時序與明確的空值處理。

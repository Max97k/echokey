# AKeyboard v0.6.2 (versionCode 8)

Google Play Internal Testing build `v0.6.2 (8)`.

## What's new

- **Estimated Fallback Usage Tracking**: records official `usageMetadata` whenever returned by the Live API, and falls back to accurate request counts plus estimated tokens (`25 tokens/sec` audio input + transcript output estimate, clearly labeled `~` / `Est.`) for transcription models like `gemini-3.5-transcribe-live` that omit server `usageMetadata`.
- **Warm-Up Connection Deduplication**: prevents duplicate WebSocket handshakes when `warmUp()` is triggered back-to-back while a matching connection is still opening.

## 更新內容（繁體中文）

- **官方優先 + 估算補齊用量統計**：支援一般 Live 模型精確記錄官方 `usageMetadata`；針對 `gemini-3.5-transcribe-live` 等未回傳 `usageMetadata` 的轉錄模型，於轉錄完成且無官方計量時自動以實際次數與音訊秒數（`25 tokens/秒`）＋輸出字數補齊統計，並在 UI 標示 `~`／`含估算`。
- **避免重複預熱連線**：修正連線尚未完成握手前重複呼叫 `warmUp()` 導致連續開啟兩條 WebSocket 的問題。

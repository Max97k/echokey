# AKeyboard v0.6.1 (versionCode 7)

Google Play Internal Testing build `v0.6.1 (7)`.

## What's new

- **Detailed Live & Usage Diagnostics**: expands `DiagnosticLog` (250 entries, 320-char detail limit) to trace WebSocket connection IDs, audio frame counts, non-interim server payload keys, raw `usageMetadata` packets, high-water deltas, background socket draining, `VoiceDictationSession` phases, and `UsageRepository` persistence alongside a live `Usage Store` snapshot in copied diagnostics (while never logging audio, transcript text, or API keys).

## 更新內容（繁體中文）

- **詳盡的 Live 與用量除錯診斷報告**：擴充 `DiagnosticLog` 容量（250 筆紀錄、單筆 320 字元），於複製診斷資訊時納入 WebSocket 連線編號、音訊影格數、非純 interim 伺服器封包欄位、`usageMetadata` 原始計量與增量明細、背景連線收尾狀態、`VoiceDictationSession` 生命週期與 `UsageStore` 目前統計快照（仍維持絕不記錄語音、辨識文字與 API Key）。

# AKeyboard v0.4.0 (versionCode 3)

Google Play Internal Testing build `v0.4.0 (3)`.

## What's new

- **Inline autofill**: the keyboard now shows system autofill suggestions (SMS one-time codes, saved passwords, passkeys) in its top bar. AKeyboard never sees the content until you tap a suggestion and needs no SMS permission.
- **Paste button** (phone keyboard and PC Bluetooth remote): inserts the latest text copied on Android. On the PC remote, line breaks become spaces so a paste never presses Enter.
- **Recent sent history** (PC remote): the last 3 sent dictations stay in memory with per-item Resend and Clear, so you can resend when the PC cursor was in the wrong window. Never written to disk.
- **Screen stays on** while holding the mic, recording or finalizing (phone keyboard and PC remote).
- **Diagnostics**: new "Copy debug diagnostics" in Settings (version, device, recent crash exit reasons, sanitized logs; never includes voice, typed text or your API key).

## 更新內容（繁體中文）

- **行內自動填入**：鍵盤頂部列可顯示系統的簡訊驗證碼、密碼、Passkey 建議；點擊前鍵盤看不到內容，也不需簡訊權限。
- **貼上按鈕**（手機鍵盤與電腦藍牙遙控）：貼上 Android 最後複製的文字；電腦端會把換行轉為空白，避免誤按 Enter。
- **最近送出紀錄**（電腦遙控）：僅存記憶體，保留最後 3 筆，可逐筆重送或清除。
- **按住說話／錄音／辨識中螢幕保持常亮**。
- **除錯診斷**：設定頁新增「複製除錯診斷資訊」（不含語音、輸入文字或 API Key）。

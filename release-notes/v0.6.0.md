# AKeyboard v0.6.0 (versionCode 6)

Google Play Internal Testing build `v0.6.0 (6)`.

## What's new

- **Daily × Per-Model API Usage Tracking**: locally records Gemini Live API token usage (`prompt`, `response`, `thoughts`, `cached`, `audio input`, and request counts) in Typed JSON DataStore with 90-day daily retention, all-time totals, and corruption recovery.
- **Live Protocol & Connection Draining**: parses top-level `usageMetadata` (including standalone frames), deduplicates cumulative per-connection counts via high-water deltas, and drains rotated WebSockets in the background to capture trailing usage without delaying text commits.
- **Settings Usage Dashboard**: adds Today / Last 30 days / All time summary cards, Daily vs. By-model views, AI Studio billing link, confirmed stats reset, and 10-locale translations.

## 更新內容（繁體中文）

- **每日 × 分模型 API 用量追蹤**：採用 Typed JSON DataStore 在本機記錄 Gemini Live API Token 用量（輸入、輸出、思考、快取、音訊輸入明細與次數），保留 90 天每日明細並持續累計總帳，含損毀自動復原保護。
- **Live 協議解析與連線背景收尾**：於 `serverContent` 檢查前解析頂層 `usageMetadata`、依連線高水位去重增量，並在連線輪替時於背景短暫保留舊連線接收尾隨用量，不延遲文字送出。
- **設定頁用量統計區塊**：新增今日／近 30 天／累計摘要卡、每日與依模型切換檢視、AI Studio 帳單連結、二次確認重設與 10 國語系翻譯。
